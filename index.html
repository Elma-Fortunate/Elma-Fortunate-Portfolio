✦ Featured Project

Credit Risk EWS & Probability of Default Modeling

Problem: Banks need to catch deteriorating loans before they default — not after. Approach: Built an end-to-end credit risk monitoring system: a rule-based Early Warning System using composite risk scoring (DPD, DTI, DSCR, LTV, revolving utilisation), then layered ML models — Logistic Regression, Decision Tree, Random Forest, and Gradient Boosting — to predict individual Probability of Default. SHAP values were used to explain every prediction to credit teams. Outputs were exported to Power BI for live portfolio dashboards and a Flask API for real-time scoring. Outcome: A production-ready monitoring system that flags at-risk borrowers, tracks daily PD drift, and delivers colour-coded risk bands directly to decision-makers.

  • Random Forest & Gradient Boosting achieved the highest AUC — consistently outperforming Logistic Regression on default detection
  • Composite risk scoring correctly tiered borrowers into Green / Amber / Orange / Red bands, validated against actual loan status
  • SHAP explainability revealed Credit Score, Revolving Utilisation, and DTI% as the top default drivers
  • Daily PD drift tracking flags loans deteriorating by >0.05 PD score overnight — enabling proactive intervention
